# Structured Evidence (`/research/evidence/`)

This directory contains verified, structured evidence notes adhering to [`evidence-standard.md`](../../research-protocol/evidence-standard.md).

### Naming Convention
`E[Agent]-[ID]-[slug].md` (e.g., `E01-001-quran-tajweed-correction-demand.md`)

Each file must specify:
- Verification Status & Confidence Level (HIGH / MED / LOW)
- Source Tier (Tier 1-4)
- Exact citation or URL
- Key finding or quote
- Linked Problem Cards
