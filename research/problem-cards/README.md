# Problem Cards (`/research/problem-cards/`)

This directory contains discrete, standardized problem cards documenting user pains, friction points, and unmet needs adhering to [`problem-card-schema.md`](../../research-protocol/problem-card-schema.md).

### Naming Convention
`PC-[ID]-[slug].md` (e.g., `PC-001-revert-salah-memorization-anxiety.md`)

Each card includes:
- Target Segment & Severity / Frequency scores
- Theological Sensitivity rating
- Current workarounds used by Muslims today
- Linked evidence notes in `/research/evidence/`
- Potential AI intervention ideas
- Red team & trust risks
