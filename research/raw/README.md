# Raw Research Data (`/research/raw/`)

This directory stores unstructured data collected during discovery:
- Interview transcripts and audio summaries
- Community forum dumps (Reddit, Discord, social media discussions)
- User survey responses (raw CSV/JSON/markdown)
- Field notes from visits to mosques, madrasahs, and conferences

**Note:** Files in this directory contain unverified, unfiltered opinions. Do not treat entries here as factual or theological evidence until validated.
