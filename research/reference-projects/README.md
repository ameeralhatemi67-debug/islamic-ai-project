# Reference Projects (`/research/reference-projects/`)

This directory contains competitive evaluations and teardowns of existing Islamic applications, tools, and platforms according to [`project-comparison-schema.md`](../../research-protocol/project-comparison-schema.md).

### Naming Convention
`REF-[project-name].md` (e.g., `REF-tarteel.md`, `REF-muslim-pro.md`, `REF-quranly.md`)

Each evaluation examines:
- Core features and AI/ML stack
- Scholarly vetting mechanism and trust safeguards
- User ratings, praise, and top complaints
- Vulnerabilities and white space for next-generation solutions
